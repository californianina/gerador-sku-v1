Estrutura do SKU
Formato: TIPO/NOME-COR-TAM
COR/CORS-PTO-M
→ Corset · Preto · M
Passo a passo
1.Confira a aba Tabelas. Para gerenciar coleções, use ⚙ Configurações.
2.Linha em branco ou ⚡ Gerar em lote para múltiplas combinações de uma vez.
3.Clique em ⧉ para duplicar uma linha existente e alterar só o que precisa.
4.Use Exportar CSV antes de fechar. Os dados do gerador não são salvos entre sessões.
Código de coleção automático
·"Verão 2026" → VER26 — 3 letras + número
·"Drop 01" → DRO01 — 3 letras + número
·"Básicos" → BAS — só letras quando não há número
·Você pode editar o código manualmente na tela de configurações se precisar.
